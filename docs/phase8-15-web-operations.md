# Phase 8-16-Web：运营增强与运行整改汇总

本文件记录 Phase 8 到 Phase 16 的落地范围和边界。

## Phase 8：发货记录关联商品/订单卡片

已落地：

- 发货记录增加 `card_id`、`order_id`。
- 聊天发货表单可选择已解析的商品/订单卡片。
- 订单卡片只允许待发货状态进入发货候选。
- 同一订单、卡片或会话商品存在 `pending` / `sent` 发货记录时，拒绝重复生成。
- 发货模板新增占位符：
  - `{order_id}`
  - `{card_title}`
  - `{card_status}`

## Phase 9：自动发货安全框架

已落地：

- 每账号自动发货配置：
  - 开关
  - 模式：人工确认 / WS 文本发送 / 平台确认发货预留
  - 必须关联卡片
  - 防重复
  - 订单状态白名单
- 发货记录预检接口。
- 平台确认发货接口未接入前，`platform_api` 模式只做预检拦截。

重要边界：

- 当前仍不调用闲鱼平台确认发货接口。
- 当前仍不做浏览器自动化发货。
- 自动化安全框架是为后续真实接口接入做保护层。

## Phase 10：商品发布管理

已落地：

- 商品草稿管理：
  - 标题
  - 描述
  - 价格
  - 库存
  - 分类 ID
  - 图片 URL
  - 草稿状态
- 发布任务管理：
  - `manual_export`
  - `platform_api`
  - `browser_automation`

重要边界：

- 当前不执行真实商品发布。
- `platform_api` / `browser_automation` 任务会被标记失败，并记录“执行器尚未接入”。

## Phase 11：任务队列抽象

已落地：

- Redis 是唯一任务投递通道，只传递 `task_id`。
- MySQL 的 `xianyu_background_tasks` 保存任务 payload、状态、结果和错误。
- API 投递失败时返回 503，并把已创建任务标记为 `failed`。
- worker 只从 Redis `BRPOP` 消费，不使用数据库轮询降级。
- 管理后台可配置队列名、启停队列并查看任务结果。

重要边界：

- Redis 不可用时不会假装排队成功。
- 商品真实发布执行器未接入，相关任务会明确失败。

## Phase 12：多账户运行增强

已落地：

- 批量启动已启用账户。
- 批量停止账户。
- 后台首页提供批量操作入口。

## Phase 13：生产安全基础

已落地：

- 用户名/密码登录、首个管理员初始化、JWT 鉴权。
- `admin` 全权限、`operator` 业务读写、`viewer` 只读。
- `/api/auth/me` 返回当前用户，前端菜单和写操作随角色收敛。
- 除 `/api/health`、`/api/auth/login`、`/api/auth/bootstrap` 外所有 `/api/*` 请求都需要：
  - `Authorization: Bearer <jwt>`
- CORS 来源支持 `XIANYU_CORS_ORIGINS` 配置。
- 只有来自 `XIANYU_TRUSTED_PROXY_IPS` 的请求才信任转发 IP 头。
- 前端使用 localStorage `xianyu_access_token` 保存 JWT。

## Phase 14：消息类型增强

已落地：

- 管理后台可从图片消息 raw payload / content 中识别图片 URL。
- 图片消息在聊天气泡中预览。

## Phase 15：通知与审计增强

已落地：

- API 写操作自动审计：
  - POST
  - PUT
  - DELETE
- 审计字段：
  - 实际操作用户
  - 客户端 IP
  - 动作
  - 目标路径
  - 成功/失败
  - HTTP 状态码
  - 时间
- 管理后台提供审计日志抽屉。

## Phase 16：本轮运行整改

已落地并实测：

- 闲鱼扫码登录由服务端持有会话和 Cookie，二维码接口可真实生成待扫码内容。
- 独立 S5 代理池、账户绑定、密码脱敏和真实闲鱼站点出站测试。
- WebSocket 发送等待平台 `mid` ACK，拒绝和超时不会记为成功。
- 断线指数退避重连，API 启动时恢复已启用账户。
- FastAPI 角色权限、审计用户/IP 和可信反代边界。
- 页面真实路由、角色菜单、移动导航和表格横向滚动约束。
- Vite 8 依赖升级，完整 npm 审计为 0 漏洞。
- 7 项后端回归测试及桌面/手机浏览器验收。
